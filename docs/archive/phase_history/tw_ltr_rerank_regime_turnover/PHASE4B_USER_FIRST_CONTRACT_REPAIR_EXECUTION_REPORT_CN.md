# Phase4B 用户第一性原则契约修正执行报告

生成时间：2026-06-14

主线依据：`docs/TW_STOCK_LTR_RERANK_REGIME_AND_TURNOVER_PLAN_CN.md`

执行依据：`docs/tw_ltr_rerank_regime_turnover/PHASE4A_REVIEW_AND_PHASE4B_USER_FIRST_CONTRACT_REPAIR_WORK_CN.md`

## 1. 本轮目标

本轮只修正产品展示契约，使其同时满足：

- 首屏更用户导向，第一眼回答“现在为什么不动 / 当前该怎么看”；
- 详情层保留受约束的真实历史回放精度，支持认真复盘；
- 仍然不进入前端、API、测试或任何产品接入实现。

本轮不写实现代码，不改 payload，不改 replay / model / training，不新增数据源，不联网。

## 2. 新的首屏顺序

首屏固定 4 个信息单元，但顺序改为用户问题优先：

| 顺序 | 信息单元 | 展示模板 | 用户价值 |
| --- | --- | --- | --- |
| 1 | 当前观察结论 / 为什么不动 | `今天不动作的主要原因：{原因短语}。` | 先回答用户最关心的问题 |
| 2 | 当前取舍摘要 | `历史回放取舍：{动作频率}，{换手压力}，{回撤水平}。` | 告诉用户这是怎样的研究取舍 |
| 3 | 方法角色 | `{用户短标签}` | 再解释该方法在系统中的位置 |
| 4 | 只读边界 | 固定免责声明 | 防止误读为操作指令 |

首屏不再以“方法角色”为第一信息单元。

首屏仍禁止展示：

- 精确费用后净值变化；
- 精确历史回放最大回撤；
- 精确动作次数；
- 精确 turnover proxy；
- 原始 `summary_notes[]`；
- `source_trace`；
- schema / created_at / safety object。

## 3. 详情层精度规则

Phase4B 修正 Phase4A 的过度等级化问题，冻结为：

```text
首屏：等级化、极简、避免误读；
详情层：受约束的精确历史回放指标 + 等级化解释 + tradeoff 同屏；
调试层：原始 trace 与 payload 对象。
```

### 3.1 详情层允许展示的精确指标

详情层允许展示以下受约束精确值：

| 指标 | 展示方式 | 必须同屏出现 |
| --- | --- | --- |
| 历史回放费用后净值变化 | 可展示百分比，但不得单独突出 | 动作次数、换手压力、最大回撤 |
| 历史回放最大回撤 | 百分比 + 低 / 中 / 高等级 | 费用后净值变化、动作次数、换手压力 |
| 历史回放动作次数 | 整数 + 偏少 / 适中 / 偏多等级 | 费用后净值变化、换手压力、最大回撤 |
| 历史回放 notional turnover proxy | 两位小数 + 较低 / 中等 / 较高等级 | 费用后净值变化、动作次数、最大回撤 |
| 相对 Top50 adaptive 差异 | 只写历史回放差异 | 至少同时写动作、换手或回撤取舍 |

详情层模板：

```text
历史回放明细：费用后净值变化 {net_return}；最大回撤 {drawdown}；动作次数 {action_count}；换手压力 {turnover_proxy}。这些数值只用于复盘，必须和取舍一起阅读。
```

### 3.2 不允许的详情层展示方式

详情层不得：

- 单独放大费用后净值变化；
- 按费用后净值变化给方法排序；
- 只显示费用后净值变化而隐藏动作、换手或回撤；
- 把相对差异写成方法优劣结论；
- 把历史回放指标写成未来判断。

## 4. 用户标签 / 系统标签边界

### 4.1 用户可见短标签

| system `research_role` | 用户短标签 | 用户说明 |
| --- | --- | --- |
| `baseline` | 对照参考 | 用来和其他研究方法比较 |
| `aggressive_rerank_research` | 高换手观察 | 动作更频繁，需同时看换手和回撤 |
| `turnover_control_research` | 少动作观察 | 更重视减少动作和换手 |
| `risk_review_reference` | 风险复盘 | 用于观察低动作和回撤取舍 |

这些用户短标签可进入首屏第 3 单元。

### 4.2 系统 / 调试层标签

以下字段或词只留在系统 / 调试层，不直接展示给普通用户：

- `baseline`
- `aggressive_rerank_research`
- `turnover_control_research`
- `risk_review_reference`
- `rerank`
- `turnover proxy`
- `source_trace`
- `schema_version`
- `safety_boundary`

### 4.3 标签使用规则

- 首屏只显示用户短标签；
- 详情层可以显示更完整的中文说明；
- 调试层才显示系统内部值；
- 不允许用用户短标签暗示优先级或推荐顺序。

## 5. 高数值展示最终规则

Phase4B 冻结最终规则：

```text
首屏不展示精确高数值；详情层允许受约束精确值；精确值必须和动作、换手、回撤取舍同屏。
```

具体规则：

1. 首屏只显示等级化取舍，不显示精确百分比、动作次数或 turnover proxy；
2. 详情层允许展示精确历史回放指标；
3. 费用后净值变化不得单独突出，不得作为排序依据；
4. 任一精确费用后净值变化出现时，必须同屏展示最大回撤、动作次数和换手压力；
5. 相对 Top50 adaptive 的差异只能写成历史回放差异，必须同时写至少一个取舍项；
6. 所有精确指标旁必须保留“历史回放 / 只读复盘”语境；
7. 不允许把高数值写成未来效果判断。
