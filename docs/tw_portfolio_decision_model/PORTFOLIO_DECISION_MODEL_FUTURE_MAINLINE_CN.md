# 组合决策模型后续主线参考文档

生成日期：2026-06-15

## 1. 文档定位

本文档只作为后续参考，不立即启动执行。

当前优先级仍是：

```text
先完成 LTR 正交数据纳入受控实验主线。
```

等正交数据主线得到结论后，再考虑是否启动本主线。

## 2. 核心判断

排序模型和策略模型解决的是两个不同问题。

### 2.1 排序模型回答什么

qlib / LTR 主要回答：

```text
在今天的股票池里，哪些股票从模型角度更值得排前面？
```

它关注的是股票本身的相对吸引力，例如：

- qlib score；
- qlib rank；
- LTR rerank；
- 技术状态；
- 未来一段时间的横截面相对表现。

### 2.2 策略模型回答什么

组合决策模型回答：

```text
在我当前已经持有什么、现金多少、成本多少、风险多少的情况下，今天到底要不要动作，动作多少？
```

它关注的不只是股票本身，还包括用户当前状态：

- 当前持仓；
- 当前现金；
- 单股成本；
- 当前盈亏；
- 已持有天数；
- 单股仓位占比；
- 股票之间的相关性；
- 行业/主题集中度；
- 当天可用换手预算；
- 交易成本；
- 是否值得为了一个更高排名股票付出换仓成本。

因此，即使暂时没有法人筹码、融资融券、月营收等新增外部数据，组合决策模型也不是简单包装 qlib 排名。它引入的是“组合状态”和“动作成本”这类排序模型没有直接建模的信息。

## 3. 为什么不能只靠每天 Top50 滚动

当前 Top50 滚动类策略清晰、可解释，适合作为 baseline。

但它天然有局限：

- 固定每天最多一买一卖；
- 卖出通常是整笔卖出；
- 买入通常是固定数量或固定规则；
- 不充分考虑持仓成本；
- 不充分考虑已持有时间；
- 不充分考虑现金约束；
- 不充分考虑股票之间的组合风险；
- 不充分考虑“排名提升是否值得支付手续费和税费”。

真实用户更关心的是：

```text
今天要不要动？
如果动，是加仓、减仓、清仓，还是只买一点？
如果现金不够，是不是应该先卖一部分？
如果排名变好但价格已经很高，是不是应该等？
```

这些问题更适合组合决策层处理。

## 4. 与正交数据主线的关系

正交数据和组合决策模型不是替代关系。

推荐结构：

```text
qlib baseline
  -> LTR / 正交数据增强评分层
  -> 组合决策模型
  -> 只读模拟动作与解释
```

正交数据提升的是：

```text
股票吸引力判断是否更准。
```

组合决策模型提升的是：

```text
在当前组合状态下，动作是否更合理。
```

两者可以叠加。

如果正交数据主线成功，组合决策模型可以使用更强的评分输入。

如果正交数据主线失败，组合决策模型仍然有价值，因为它仍可利用当前持仓、现金、成本、换手预算和风险约束改善动作质量。

## 5. 第一阶段建议：规则化组合优化器

不建议第一步直接做强化学习。

第一阶段应先做一个可解释、可回放、可审查的规则化组合优化器。

输入：

- qlib rank / score；
- LTR rank / score，如果可用；
- 当前持仓；
- 当前现金；
- 成本价；
- 当前盈亏；
- 已持有天数；
- 技术状态；
- 市场状态；
- 价格位置风险；
- 单股最大权重；
- 总持仓数量上限；
- 单日最大买卖次数；
- 手续费与交易税。

输出：

```text
今日不动作
买入 TWxxxx：使用 10% 资金
卖出 TWxxxx：卖出 30% 持仓
减仓 TWxxxx：卖出 20% 持仓
保留 TWxxxx：排名下降但未触发换仓阈值
```

目标函数可以是：

```text
预期吸引力
- 交易成本
- 换手惩罚
- 回撤风险惩罚
- 单股集中度惩罚
- 相关性/同类持仓惩罚
- 追高风险惩罚
```

用户看到的不是公式，而是简单解释：

```text
今天建议不动作：新候选优势不够覆盖换仓成本。
今天建议小幅减仓：该股排名转弱且仓位偏高，但未到清仓条件。
今天建议买入：候选排名靠前、趋势确认、组合中同类暴露不高。
```

## 6. 第二阶段建议：监督学习策略模型

在规则化优化器稳定后，可以把历史回放构造成训练数据。

样本单位可以是：

```text
某一天、某个当前组合状态、某个可选动作。
```

特征包括：

- 当日候选股票特征；
- 当前组合状态；
- 当前现金；
- 持仓股特征；
- 市场状态；
- 交易成本；
- 可选动作类型。

标签可以是：

```text
执行该动作后未来 5/10/20 日组合净收益
执行该动作后未来最大回撤
执行该动作是否优于不动作
```

模型目标不是预测单只股票涨跌，而是学习：

```text
在当前组合状态下，哪个动作更值得做。
```

这比 LTR 更接近真实用户问题。

## 7. 第三阶段建议：离线强化学习探索

强化学习可以研究，但不应作为第一版主线。

原因：

- 样本量有限；
- 容易过拟合某一段行情；
- 动作空间大；
- 奖励函数很敏感；
- 如果手续费、税费、滑点、最小交易单位不真实，回测收益会失真；
- 解释性弱，不符合当前用户第一性原则。

如果后续要做，应采用离线研究支线：

状态：

```text
市场状态 + 候选股票特征 + 当前持仓 + 现金 + 成本 + 风险暴露
```

动作：

```text
目标仓位变化，例如买入/加仓/减仓/清仓/不动
```

奖励：

```text
手续费税费后收益
- 回撤惩罚
- 换手惩罚
- 集中度惩罚
```

验收必须和规则化优化器、Top50 baseline 对比。

## 8. 用户第一性原则

本主线如果未来启动，必须保持：

- 简单：前端只展示今日模拟动作、原因、风险，不展示复杂优化公式；
- 准确：所有回放必须 next-day execution，扣手续费和税费；
- 清晰：区分“模型排序”和“组合动作”；
- 实用：必须告诉用户为什么今天动或不动，以及动多少；
- 克制：不得包装成真实投资建议，不连接券商，不自动下单。

推荐前端表达：

```text
今日模拟动作
动作类型：小幅买入 / 小幅减仓 / 保留 / 不动作
原因：排名、趋势、持仓成本、换手成本、组合集中度
影响：现金变化、持仓变化、预计手续费税费
```

不推荐前端表达：

```text
保证赚钱
上涨概率
目标价
真实买入/卖出按钮
一键跟单
```

## 9. 后续启动条件

建议满足以下条件后再启动：

1. LTR 正交数据主线已收尾；
2. 当前默认 Top50 adaptive baseline 继续可稳定日更；
3. 模拟账户持仓数据结构稳定；
4. 回放引擎支持部分买卖和现金约束；
5. 用户确认要从“排序研究”进入“组合动作模拟”。

### 10.1 LTR 论文：保留排序层，但不无限调参

对应论文：

```text
2012.07149 Building Cross-Sectional Systematic Strategies By Learning to Rank
```

纳入方式：

- 保留 qlib -> LTR rerank 的两阶段结构；
- 把 LTR 定位为“股票吸引力排序层”；
- 后续只有在正交数据进入后，才值得继续验证 LTR 是否有增量；
- 不再把无正交信息的 LTR 反复调参作为主路线。

对本主线的影响：

```text
组合决策模型不替代排序层；
它接收 qlib/LTR 输出，并决定动作与仓位变化。
```

### 10.2 Context-aware / regime 论文：市场状态进入决策层

对应论文：

```text
2105.10019 Context-Aware Re-Ranking
1707.05552 Momentum / Contrarian Market Conditions
```

纳入方式：

- 不直接照搬 Transformer reranker；
- 吸收“同一排序信号在不同市场状态下意义不同”的结论；
- 在组合决策模型中加入 normal / caution / risk-off；
- 在风险状态下提高动作门槛、降低换手、限制追高。

对本主线的影响：

```text
市场状态不是前端装饰字段；
它应影响今天是否动作、动作幅度和换手预算。
```

### 10.3 Spatio-temporal momentum：股票之间的关系要进入组合状态

对应论文：

```text
2302.10175 Spatio-Temporal Momentum
```

纳入方式：

- 吸收“单只股票自身趋势 + 其他资产/市场状态共同影响决策”的思想；
- 后续组合决策模型应关注股票之间的相关性、同类暴露、组合集中度；
- 不直接用深度 joint-signal 模型作为第一版。

对本主线的影响：

```text
策略模型不能只看某一只股票排名；
它还要看买入或卖出这只股票后，整个组合是否更稳。
```

### 10.4 交易成本与 decision-focused 论文：组合层是主策略的一部分

对应论文：

```text
1904.08925 The impact of proportional transaction costs on systematically generated portfolios
2605.01176 Decision-Induced Ranking Explains Prediction Inflation and Excessive Turnover
```

纳入方式：

- 把手续费、交易税、换手率作为策略目标的一部分；
- 引入 no-trade buffer、confidence gap、partial rebalance；
- 不再把“每天一买一卖、卖就全卖”作为唯一动作模板；
- 强制报告净收益、回撤、动作次数和换手。

对本主线的影响：

```text
组合决策模型第一阶段应先做规则化组合优化器；
它要学习或规则化决定“不动、买一点、卖一部分、减仓、清仓”。
```

### 10.5 强化学习论文：只作为后置研究支线

后续补充论文包括 FinRL 与 portfolio RL。

纳入方式：

- 参考状态、动作、奖励、交易成本建模；
- 不作为第一阶段实现；
- 必须等规则化优化器和监督策略模型稳定后，再开离线研究支线。

对本主线的影响：

```text
当前主路线不是直接 RL；
当前主路线是可解释、可回放、可审查的组合优化器。
```

## 11. 论文结论带来的路线调整

基于第一批论文和项目后续实验，本后续主线应明确做以下调整：

- 从“继续调 LTR”转为“排序层 + 组合动作层”；
- 从“固定买卖一支”转为“部分调仓和不动作机制”；
- 从“只看股票排名”转为“排名 + 当前持仓 + 成本 + 市场状态 + 组合风险”；
- 从“追求模型复杂度”转为“先保证动作可解释、低换手、扣费后有效”；
- 从“直接 RL”转为“规则化优化器 -> 监督策略模型 -> 离线 RL 研究”。

## 12. 建议后续 Phase

### Phase P0：需求与合同冻结

冻结：

- 输入数据；
- 当前持仓状态格式；
- 可选动作集合；
- 费用税费；
- 最小交易单位；
- 风险约束；
- 只读安全边界。

### Phase P1：规则化组合优化器

实现可解释规则：

- 不动作阈值；
- 部分买入；
- 部分卖出；
- 最大单股权重；
- 最大单日换手；
- 最小持有天数；
- 现金约束。

### Phase P2：历史回放验证

比较：

- Top50 adaptive baseline；
- Phase1C simple LTR；
- 规则化组合优化器；
- 加入正交数据后的评分层，如果已通过。

报告：

- 收益；
- 回撤；
- 动作次数；
- 换手率；
- 手续费税费；
- 分年份；
- 分市场状态；
- 用户可读动作样例。

### Phase P3：前端只读模拟动作

只展示：

- 今日模拟动作；
- 动作原因；
- 预计影响；
- 历史回放表现；
- 风险提示。

### Phase P4：监督学习策略模型探索

在规则化优化器通过后再做。

### Phase P5：离线强化学习研究支线

仅作为研究探索，不默认进入前端。

## 13. 一句话总结

组合决策模型值得做，因为它解决的是“在当前持仓和成本约束下怎么行动”，不是简单重排股票；但第一步应从可解释的规则化组合优化器开始，等正交数据主线收尾后再启动。
