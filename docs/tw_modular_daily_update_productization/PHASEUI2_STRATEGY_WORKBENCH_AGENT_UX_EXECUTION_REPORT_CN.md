## 2. Frontend-design 设计计划

主题：台湾股票量化研究策略工作台。受众：每天复盘模型信号、候选名单、模拟账户状态的研究型用户。页面任务：让用户在 1 分钟内理解今天策略状态，并能追问 Agent 解释候选、排名、阻断原因和数据新鲜度。

颜色 token：

- `Workbench Ink #111827`：标题、股票代码、关键数值。
- `Research Blue #1D4ED8`：排名锚点、测试窗口轨道。
- `Paper Surface #FBFDFF`：只读信息区底色。
- `Grid Line #E8EDF3`：研究台分隔线。
- `Review Amber #F59E0B`：需复核/观察状态。
- `Ready Green #16A34A`：通过/可用状态。

字体/字重角色：

- 标题：沿用现有 Ant/Vue 体系，600 权重，短标题只负责命名工作区。
- 正文：现有 UI 字体，400/500 权重，减少工程术语。
- 数据/代码类 caption：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`，用于股票代码、排名号和扫描锚点。

布局概念：顶部 `今日策略总览` 负责当日状态，下面 `候选名单` 左右拆成 `候选调入` 与 `调出复核`，再由 `历史模拟` 接住测试窗口、费用/税费、结果指标、覆盖状态。桌面双列扫描，移动端自然单列。

签名元素：轻量交易日状态轨道，先在历史模拟落地为 `测试窗口 -> 费用/税费 -> 结果指标 -> 覆盖状态`；候选名单用稳定排名列形成每日复盘的扫描锚点。

自我批评：本次没有采用暖米色杂志风、深色霓虹终端风、报纸式密排、hero 或渐变装饰；视觉风险只放在“状态轨道 + 等宽排名列”这一个研究台元素上，避免模板化 tag 堆叠和工程审计面板感。
